# Clause Wheel

Interactive clause-dependency wheel for a set of general conditions of sale (Pon Power BV, version 150219, 2019, EN).

- 24 articles as segments, 54 typed links as chords, 14 outside documents as spokes
- Every link carries a verbatim quote from both ends, script-verified against the source text
- Single self-contained `index.html`, no dependencies, no tracking

Independent tech demo built on a publicly available document. Not legal advice. Not produced by, affiliated with or endorsed by Pon Power BV or Caterpillar Inc. The source document governs.

Source: https://www.zeppelin-cat.com/application/files/2815/5049/7804/General-conditions-Pon-Power-BV-2019-EN.pdf
